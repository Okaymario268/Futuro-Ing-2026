# Component photos

Drop the product photos of the vehicle's components here. Once they are in this
folder I'll wire them into the README **Materials** table and the project website
as a photo gallery.

Suggested filenames:

| File | Component |
|------|-----------|
| `arduino-uno-q.png` | Arduino UNO Q |
| `l298n.png`         | L298N motor driver |
| `dc-motor.png`      | DC drive motor |
| `servo.png`         | Steering servo |
| `gy-521.png`        | GY-521 (MPU-6050) gyroscope |
| `camera.png`        | Logitech camera |
| `battery.png`       | 12 V battery |
| `jumpers.png`       | Jumper cables |

> Note: images pasted into a chat can't be committed automatically — they have to
> exist as files in this folder for git to track them.
