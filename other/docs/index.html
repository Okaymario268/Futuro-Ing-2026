About the project

FuturoIng is an autonomous vehicle built on the Arduino UNO Q for the WRO Future Engineers challenge. It steers with a servo, drives with a DC motor through an L298N driver, holds a straight heading with an MPU-6050 gyroscope, and detects coloured pillars with a Logitech camera.

Engineering journey

The problems we solved on the road from the first prototype to the final robot.

🔴 Raspberry Pi — first version

Setup needed an external keyboard, monitor & mouse. Worse, the Pi's PWM pulse frequency didn't match the servo, so steering was never accurate or repeatable.

🟢 Switch to Arduino UNO Q

Same dual nature (Python + C/C++), so we ported the code. C/C++ drives the servo & DC motor with hardware-timed PWM; Python runs the camera and data handling.

🎛️ Servo calibration via web UI

The detached servo's centre was unknown — the first command asked for −52° (outside the 0–180° range). A browser slider over the UNO Q's RouterBridge let us measure the real values: orientation off by ~270°, centre = 79°.
